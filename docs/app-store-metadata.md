### 【概要 (Description)】(最大4,000文字)
```text
たった15文字で綴る、ふたりだけの愛おしい日常。

「15文字デート」は、みんなが考えた理想のデートプランを投稿・投票し、「今日なにする？」と迷った時にスロット演出でランダム決定できる、新感覚のカップル＆恋愛コミュニティアプリです。

アカウント登録やログインは一切不要！
アプリを開いたその瞬間から、ふたりのデートのアイデア出しや、言葉を紡ぐ楽しさを体験できます。

━━━━━━━━━━━━━━━━━━━━
15文字デート の 4大特徴
━━━━━━━━━━━━━━━━━━━━

◆ 1. 厳格な「ピッタリ15文字」縛り
14文字でも16文字でも投稿できません。
俳句や短歌のように、言葉を足したり引いたりしながら、原稿用紙の15マスを埋めていく独特のパズル感と大喜利の楽しさを味わえます。
（例: 「古本屋で五百円分選び合ってみる」「深夜のドライブで静かな海を見に」）

◆ 2. 運命のデートルーレット
「次のデート、どこ行こう？」「今から何する？」と迷った時に大活躍！
スロットマシンのようなワクワクする演出で、みんなが投稿した珠玉のデートプランから1つをランダムに決定します。

◆ 3. みんなの「いいね！」ランキング
投稿されたプランには誰でもワンタップで「いいね！」を投票可能。
「人気順」「新着順」「ランダム」で並び替えができ、読んでいるだけでキュンとするような、みんなの日常の幸せをおすそ分けしてもらえます。

◆ 4. アートZINE（書籍化）プロジェクト連動
本アプリに投稿された素晴らしいデートプランは、企画者（画家・翔大）によるリトルプレス冊子『理想のデート15文字ZINE』に厳選収録され、個展や展示会、BASEショップを通じて実際の本として出版・全国展開されます。
あなたの紡いだ15文字が、世界にひとつのアート作品になります。

ふたりの何気ない一日を、特別な思い出に。
あなたの理想のデートを、15文字で教えてください。
```
