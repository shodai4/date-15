# 理想のデートプランを15文字でどうぞ。☕✨

> **「たった15文字で綴る、ふたりだけの愛おしい日常。」**  
> みんなの理想のデートプランを投稿・投票・ルーレットで決めるWebアプリケーション。

---

## 📖 コンセプト & ルール

1. **厳格な「ピッタリ15文字」縛り**:
   - 14文字でも16文字でも投稿できません。
   - 俳句や短歌のように、言葉を削ったり足したりするパズル感と大喜利の面白さを楽しめます。
2. **運命のデートルーレット**:
   - 「今日のデート何する？」と迷ったカップルが、スロット演出でランダムに1つのプランを決定できます。
3. **みんなのいいね👍ランキング**:
   - 投稿されたプランにいいねして、人気順・新着順・ランダムで閲覧できます。
4. **ZINE（書籍）化プロジェクト連動**:
   - 投稿された珠玉の15文字プランは、企画者（画家・翔大）によるアートZINE（リトルプレス冊子）として厳選出版されます。

## 🗄️ Supabase データベース設定（全体共有する場合）

SupabaseのSQLエディタで以下のSQLを実行するだけで、全ユーザー間での投稿といいねがリアルタイム共有されます。

```sql
-- 1. テーブル作成
create table if not exists date_plans (
  id bigint generated by default as identity primary key,
  text varchar(15) not null,
  likes integer default 0 not null,
  created_at timestamp with time zone default timezone('utc'::text, now()) not null
);

-- 2. セキュリティ (RLS) 有効化
alter table date_plans enable row level security;

-- 3. 全体読み取り許可（誰でも閲覧可能）
create policy "Allow public select" on date_plans
  for select using (true);

-- 4. 投稿許可（ピッタリ15文字の厳格チェック）
create policy "Allow public insert" on date_plans
  for insert with check (char_length(text) = 15);

-- 5. いいね加算許可 (RPC関数)
create or replace function increment_likes(row_id bigint, delta int)
returns void as $$
begin
  update date_plans
  set likes = greatest(0, likes + delta)
  where id = row_id;
end;
$$ language plpgsql security definer;

-- 6. 初期プリセット10選の投入
insert into date_plans (text, likes) values
  ('散歩中の可愛い犬を数えて歩こう', 142),
  ('古本屋で五百円分選び合ってみる', 218),
  ('昔ながらの駄菓子屋で三百円豪遊', 175),
  ('レンタルビデオでジャケ買い勝負', 98),
  ('ガチャガチャを二人でフルコンプ', 164),
  ('深夜のドライブで静かな海を見に', 289),
  ('デパ地下試食コーナー全種類制覇', 112),
  ('ボードゲームカフェで真剣勝負す', 134),
  ('見知らぬ駅でふらり途中下車する', 203),
  ('早朝の市場で熱い朝ラーメン食う', 251);
```
